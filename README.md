# Reyes Official iOS App

This is the iOS version of the Reyes Official App. The app is developed entirely with SwiftUI in xcode16.2 and tested with XCTest, it also uses the Stripe iOS library and is configured to connect with the Google Cloud and firebase services.

## Requirements

Ensure that the following tools are installed on your system:

- [XCode](https://developer.apple.com/xcode) 16.2 or higher
- [Firebase CLI](https://firebaseopensource.com/projects/firebase/firebase-tools) Optional
